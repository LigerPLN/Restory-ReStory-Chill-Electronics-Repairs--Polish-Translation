# Restory-ReStory-Chill-Electronics-Repairs--Polish-Translation
Polskie tłumaczenie gry Restory – pliki gotowe do instalacji i aktualizacji.

## Instalacja

(Przed instalacją wykonaj kopię oryginalnych plików.)

1. Zamknij grę.
2. Wypakuj pliki.
3. Skopiuj zawartość do katalogu gry. (...\SteamLibrary\steamapps\common\Restory)
4. Przy kopiowaniu wybierz „Zastąp pliki”.
5. Uruchom grę.
